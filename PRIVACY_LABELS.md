# Privacy labels (Apple Privacy Nutrition Label / Google Data Safety)

Every real data flow in the current code, mapped to both stores' disclosure
categories. Use this to fill out App Store Connect's "App Privacy" section
and Google Play Console's "Data safety" form directly — don't re-derive it
from the privacy policy prose, derive it from this (and re-generate this
file if a data flow changes).

**No persistent device or account identifier is generated or sent
anywhere** — there is no login, no device ID, no install ID. Every flow
below is tied only to the single request it's part of (plus a short-lived,
IP-keyed rate-limit counter — see "IP address" below), never to a
person across sessions, so "Data Not Linked to You" applies throughout
unless noted otherwise.

## Sent to Anthropic (AI provider), via this app's own Netlify functions

| Feature | What's sent | User-authored free text? | Consent gate |
|---|---|---|---|
| Chat | message text, recent conversation history, up to 3 saved "memory" notes | Yes | None for the message itself (core feature); memory notes require a separate opt-in |
| Quick check-in | one message | Yes | `mc_chat_consent` (shared with Chat) |
| Explain-how-I-feel rewrite | one draft | Yes | `mc_chat_consent` |
| AI Coach | app-generated summary: goal titles/streaks, habit names/streaks, this week's mood average, health averages (sleep/water/movement), money totals (spent/saved, no currency) | Partially — goal/habit **titles** are user-authored; the rest is computed | `mc_coach_consent` (separate, names exactly these categories) |
| Agent "today's plan" | goal choice, work-shift times, mood/sleep/exercise aggregates, **and the person's free-text note, plus up to 3 earlier notes from memory** | Yes | `agentConsent` checkbox, per-plan |

**Apple category:** User Content (messages, notes) + Health & Fitness (mood,
sleep) + Financial Info (money log, Coach only) — all "Not Linked to You".
**Google category:** Messages / Personal info (free text) and Health and
fitness (mood, sleep) under "Data is collected but not linked to a user
identity", processed, not sold, with a path to request deletion (Privacy
Passport's delete-everything).

## Sent to this app's own Netlify functions, not forwarded to the AI

| Feature | What's sent | Identifying? |
|---|---|---|
| Usage stats (opt-in) | day index, per-feature usage counts, UI language, pilot-code flag | No — no free text, no identifiers |
| Feedback / opinions (pilot mode) | 1-5 rating, optional free-text opinion, optional pilot code, language | The opinion text is **user-authored** and, once an admin approves it, **shown publicly** on the in-app reviews page — say this plainly wherever opinions are collected |
| Admin dashboard | an admin password (hashed server-side, never stored in plaintext) | Owner-only, not applicable to end users |

**Apple/Google category:** Usage Data / App Interactions (stats);
User Content (feedback text, since it's authored and may go public).

## IP address

Used transiently by chat.js, feedback.js, and stats.js to rate-limit abuse
(a short-lived counter in Netlify Blobs, keyed by IP, reset every 10
minutes for chat). Not logged alongside message content, not used to
identify a person across sessions.

**Apple category:** Diagnostics (or omit if Apple's current guidance treats
transient rate-limiting IP use as not requiring disclosure — check current
guidance, this changes). **Google category:** typically declared under
"Device or other IDs", purpose "App functionality" (fraud prevention /
security), not shared, not used for the app's own advertising.

## RevenueCat (once configured — see mobile/README.md)

Once in-app purchases are set up, RevenueCat receives: an anonymous App
User ID (generated by RevenueCat, not by this app), purchase/subscription
events, device platform. This is a **new third-party processor** as soon
as it's configured — add it to the privacy policy and to both stores'
forms at that point; it isn't live yet in the current code.

**Apple category:** Purchase History (Linked to You — RevenueCat's App
User ID does persist per installation, unlike everything else in this
app). **Google category:** Purchase history, linked to user.

## Stored only on the device, never transmitted anywhere

Goals, habits, daily/weekly reviews, health logs, finance logs, journal
entries, mood logs (except the aggregate sent to Coach/Agent as described
above), the personal Calm Plan, saved exercise history, streaks, all
preferences. All in `localStorage`; Privacy Passport (in-app) lets someone
export or delete all of it, and "delete everything" scans every `mc_`
prefixed key generically (not a hardcoded list), so new local-only
features are covered automatically.
